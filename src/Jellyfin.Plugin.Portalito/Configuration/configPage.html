Import / export configuration
Paste a .env (PORTALITO_*=value lines) or a JSON object and press Import to fill every field at once, then review and press Save. Export writes the current values here to copy to another server. Nothing is saved until you press Save.
How Jellyfin's own ffmpeg reaches this server. Leave empty to use the server's own address (its port, HTTPS and base path). "Save and test" checks it.
Leave email and password empty to use anonymous device activation (catalog and VOD only). An account holds one session at a time, so a dedicated account avoids signing out your phone.
Fills in synopses and posters Portalito leaves blank, and powers the Destacado rows below.
Rows separated by ;, each Label | source | key=value .... Sources: trending, popular-movies, popular-tv, top-movies, top-tv, upcoming, now-playing, airing-today, on-air, discover-movies, discover-tv. Discover takes country=, lang=, genre= (16 = animation), nogenre=, sort=, year=, minvotes=, network= (a platform's own series: netflix, apple, disney, hbo, prime, paramount…), provider= + region= (what streams on a platform in a country) (commas mean "or", e.g. country=JP,KR); trending takes type=movie|tv and window=day|week. Only titles your portal has are shown. Needs the TMDB key. Comes pre-filled with a default set of rows; clear it to use the portal's own rows instead.
Leave empty to use the built-in Portalito logo. Jellyfin caches channel images: after changing this, open the channel and use "Refresh metadata" with "Replace existing images".
The portal sends guide times without a time zone. If the guide is shifted by some hours, put the zone the portal uses here (an IANA name). Empty means the server's own.
Jellyfin lists channel folders A-Z unless the app asks for another order. With this on, a Destacado row's titles come best-rated first (TMDB's rating in TMDB rows, else the portal's; unrated titles last). Picking another order in the app's sort menu still works.
Jellyfin's "Next Up" only reads libraries, never channels. With this on, the series people watch in the channel are mirrored into a TV library that's hidden from every user's menus but feeds Next Up and Continue Watching. Only followed series are mirrored (watched in the last 60 days, or marked favorite), not the catalog. Turning it off stops the sync; delete the library from Dashboard → Libraries to remove it.
Where the library's small .strm/.nfo files and posters are written. Jellyfin must be able to write it.
Leave off unless the portal hosts present invalid certificates: without verification, anyone on the network path can capture your account login.
Advanced: portal protocol
The identity and codes your portal's middleware expects. Blank by default — fill in your own portal's values.
Leave Device SN blank to auto-provision a free device; this salt derives its serial (MD5(snToken + salt)) if the portal doesn't return one.
Comma-separated code:Label pairs. Empty means no VOD catalogs.
Advanced: CDN Content-Auth signing
How live streams are signed for your portal's CDN. Leave blank unless your portal requires it; a wrong value only shows up as live streams that won't play.
Advanced: proxy signing secret
Every stream URL the plugin hands out is signed with a secret stored here. Rotating it revokes all of them at once — including the permanent ones in the "Siguiendo" library files, which are rewritten right away — and stops anything playing. Use it if a stream URL leaked.
