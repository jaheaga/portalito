Import / export configuration
Paste a .env (PORTALITO_*=value lines) or a JSON object and press Import to fill every field at once, then review and press Save. Export writes the current values here to copy to another server. Nothing is saved until you press Save.
How Jellyfin's own ffmpeg reaches this server. Leave empty to use the server's own address (its port, HTTPS and base path). "Save and test" checks it.
Leave email and password empty to use anonymous device activation (catalog and VOD only). An account holds one session at a time, so a dedicated account avoids signing out your phone.
Fills in synopses and posters Portalito leaves blank. Never changes which titles are listed.
The portal sends guide times without a time zone. If the guide is shifted by some hours, put the zone the portal uses here (an IANA name). Empty means the server's own.
Leave off unless the portal hosts present invalid certificates: without verification, anyone on the network path can capture your account login.
Advanced: portal protocol
The identity and codes your portal's middleware expects. Blank by default — fill in your own portal's values.
Comma-separated code:Label pairs. Empty means no VOD catalogs.
Advanced: CDN Content-Auth signing
How live streams are signed for your portal's CDN. Leave blank unless your portal requires it; a wrong value only shows up as live streams that won't play.
